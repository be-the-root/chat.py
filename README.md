# chat.py

a terminal based little scrpt that can be used as a tool for many things 

built as a learning project to practice python fundamentals: file / loops / funtions / string manipulation (hehe this word sounds cool) and terminal styling

## features

**the ledger** - a note taking tool with simple commonds

**password generator** - a password generator that generaates password and also tests the strength of the generated password

**antique quiz** - 5 questions based on antiques

**file browser** - navigate, search, inspect files on ur local device

**dice roller** - roll any sided dice (or can be used as      random  number generator)

**magic 8 ball** - ask yes/no questions

**coin flip** - heads or tails


## tech stack

language - python
standerd library- time, random , string, os , datetime

* no external dependencies

## installation

### 1. clone the repository

```bash
git clone https://github.com/be-the-root/chat.py.git
cd chat.py
```
### verify python is installed

```bash
python3 --virsion
```
should output python 3.8.x or higher , if not, install python

* debian/ubuntu/kali: sudo apt install python3
* macos: brew install python3
* windows: download from python.org

## 3 run the script

```bash
python3 chat.py
```
follow the instructions and have fun!!!!
